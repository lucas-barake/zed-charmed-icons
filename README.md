# Charmed Icons+ for Zed

A charming icon theme for [Zed](https://zed.dev) with full file and folder icon support.

All icons are from [Charmed Icons](https://github.com/littensy/charmed-icons) by [littensy](https://github.com/littensy), licensed under MIT.

## Variants

- **Base** (dark)
- **Light**
- **Soft** (dark)
- **Warm** (dark)

## Install locally

1. Clone this repository
2. In Zed, open the command palette (`Cmd+Shift+P`)
3. Run `zed: install dev extension`
4. Select the cloned directory
